# Team Lalli61 - Standard Document Footer

## Purpose

Every official Team Lalli61 Markdown document must finish with the same
professional footer.

This creates consistency across all projects and makes it easy to
identify the latest version of every document.

------------------------------------------------------------------------

# Standard Footer

``` md
---

# Document Information

**Version:** 1.0
**Created:** 05 August 2026
**Last Updated:** 05 August 2026

---

Designed & Created by Team Lalli61

GSD – Get Stuff Done
```

------------------------------------------------------------------------

# Rules

-   Every official Markdown document must include this footer.
-   Update the **Version** whenever significant changes are made.
-   Update the **Last Updated** date every time the document is edited.
-   The **Created** date never changes.
-   Keep the footer identical across every Team Lalli61 project.
