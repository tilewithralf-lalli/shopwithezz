## Version 1.1.0 - Current Development Version

**Status:** Feature-complete app experience; release system and final build still pending  
**Last Updated:** 09 August 2026

### Added

- Added Hands-Free commands directly to the Shopping List so shoppers do not need to leave the list to use voice controls.
- Added the spoken command **“Read my collected”**.
- Added commands to read the remaining list and the complete list.
- Added accepted read-list phrases including:
  - “What is left?”
  - “What's left?”
  - “Read my list”
  - “Read my collected”
  - “Read my whole list”
  - “Read my complete list”
  - “Read my full list”
  - “Read all my items”
- Added voice commands for adding, collecting, uncollecting, increasing, and decreasing shopping items.
- Added voice deletion commands for collected items and the whole list.
- Added serious confirmation before any voice deletion is completed.
- Added a standard Settings screen.
- Added Change Profile.
- Added Extras with Hands-Free Commands, Import a List, Share List, and How to Use.
- Added Send Feedback.
- Added app backup with a user-selected folder.
- Added restore from a user-selected ShopWithEzz backup file.
- Added About and App Version with the complete Team Lalli61 information.
- Added a proper scrollable How to Use screen.
- Added the complete list of recognised speaking commands to How to Use.
- Added a large red Hands-Free notice explaining how to start with **“I need”**.
- Added clear instructions that **“I need”** is only required when Shopping Mode starts.
- Added the 15-second speaking rule and instructions to say **“I need”** again after the timer runs out.
- Added a visible **Read Collected** control on the Shopping List.

### Improved

- Simplified and refreshed the home-screen layout.
- Reduced the number of competing tap options on the home screen.
- Moved Share List and How to Use into Settings.
- Repositioned the home content and Settings control for better visibility.
- Added the approved woman-pushing-trolley artwork to the home header.
- Improved the About area so the complete Team Lalli61 information appears inside the green About field.
- Improved backup so the user can choose a phone folder or connected storage location where supported.
- Improved restore validation and confirmation before replacing current app data.
- Improved item editing so tapping the keyboard **Done** key saves Quantity or Price changes and returns directly to the Shopping List.
- Improved the speaking-command descriptions so users know exactly what to say and what each phrase does.

### Removed

- Removed Delete All Data from Settings because it was not required for this app.
- Removed extra home-screen shortcuts that made the start page feel crowded.

### Tested and Approved

- Quick and Fast Test passed on the real Android phone.
- Smart and Really Smart voice test passed.
- App restart and saved-data test passed.
- Backup creation test passed.
- Restore test passed after deliberately changing app data.
- Offline-use and offline-persistence test passed.
- Final Granny Test passed.
- Updated How to Use speaking instructions approved on the real phone.

### Documentation

- Added the interactive ShopWithEzz Project Tracker.
- Completed and approved the ShopWithEzz Bible.
- Completed and approved the ShopWithEzz Roadmap.
- Completed and approved the ShopWithEzz Master Plan.
- Completed and approved the ShopWithEzz Ideas document.

### Still Required Before Release

- Complete the Backup Log and standard document-footer review.
- Implement and test the 31-day beta trial.
- Implement and test automatic trial lock.
- Implement and test the one-time purchase and permanent unlock.

## Changelog Rules

- Add the newest version or important development update at the top.
- Use wording that ordinary users can understand.
- Record Added, Improved, Fixed, Removed, Tested, and Documentation items where relevant.
- Do not claim that an item is complete until it has been tested and approved.
- Keep the version and release information consistent with the app, About screen, public download page, and Backup Log.
- Update the document version and Last Updated date after significant changes.
