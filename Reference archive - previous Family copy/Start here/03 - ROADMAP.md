# 03 - SHOPWITHEZZ ROADMAP

## Purpose

This roadmap records the approved development phases, milestones, testing order, and release path for ShopWithEzz.

Work moves through one step at a time:

1. Complete the step.
2. Test it on a real device where applicable.
3. Get approval.
4. Record it as Done.
5. Back up the approved work.
6. Move to the next step.

---

## Status Key

- **Done** - Completed, tested, and approved.
- **In Progress** - The current active step.
- **Pending** - Not started yet.
- **Needs Attention** - A problem must be resolved before continuing.

The live status for each step is maintained in `00 - SHOPWITHEZZ PROJECT TRACKER.html`.

---

## Phase 1 - Core Shopping App

**Status: Done**

Completed milestones:

- Home screen and profile greeting.
- Shopping list creation and management.
- Add, edit, collect, uncollect, increase, decrease, and remove items.
- Store and category support.
- Budget, Spent, and Left calculations.
- Product scanner.
- Typed-list importing.
- Photo-list importing where supported.
- List sharing and printing.
- Local device storage.

Approval result: The core shopping experience is working on the real Android phone.

---

## Phase 2 - Hands-Free Shopping

**Status: Done**

Completed milestones:

- Voice controls available directly from the Shopping List.
- Add an item by voice.
- Collect and uncollect an item by voice.
- Increase and decrease quantity by voice.
- Read the remaining list.
- Read the collected list.
- Read the complete or whole list.
- Delete collected items by voice with confirmation.
- Delete the whole list by voice with confirmation.
- Stop listening command.
- Clear spoken responses using everyday wording.

Approval result: Smart and Really Smart voice testing passed on the real phone.

## Phase 6 - Release System

**Status: Pending**

Required milestones:

1. Implement the free 31-day beta trial.
2. Implement the automatic trial lock.
3. Implement the one-time purchase.
4. Confirm there are no subscriptions.
5. Implement permanent unlock after purchase.
6. Implement purchase restoration where supported.
7. Test the complete trial and unlock journey.
8. Add final version, build number, release type, and release date.

Completion rule: Trial, lock, purchase, permanent unlock, and restoration must all be tested before release.

---

## Phase 7 - Final Backup and Local Android Build

**Status: Pending**

Required milestones:

1. Confirm every previous phase is Done.
2. Create a final approved source backup.
3. Record the backup in `07 - BACKUP LOG.md`.
4. Create the final Android build locally.
5. Install the final build as a clean installation on the real Android phone.
6. Test app launch, list creation, budget, voice, Settings, backup, and restore.
7. Confirm the final build version and release information.
8. Preserve the approved final build and matching source backup.

Important: Do not create the final app build before every earlier phase is complete and approved.

---

## Phase 8 - Public Download Page

**Status: Pending**

Required milestones:

1. Prepare the ShopWithEzz public information page.
2. Explain the app, trust promise, features, privacy, trial, and price.
3. Provide the Team Lalli61 feedback email.
4. Show the Android download option on Android devices.
5. Show the professional iOS Coming Soon message on iPhone and iPad.
6. Test the complete one-link download journey.
7. Confirm the page points only to the approved current release.

---

## Future Improvements

Future ideas belong in `05 - IDEAS.md` and must not delay the approved release unless they are required for safety, reliability, privacy, or release compliance.

Any future feature must:

- Support the ShopWithEzz Bible.
- Pass the Granny Test.
- Keep the app quick, smart, fast, and reliable.
- Be built and approved one step at a time.

---

## Definition of Release Ready

ShopWithEzz is release ready only when:

- Every required tracker item is Done.
- Documentation matches the finished app.
- The release system is working and approved.
- A final source backup exists.
- The local Android build passes clean-install testing.
- The public download journey is accurate and tested.
