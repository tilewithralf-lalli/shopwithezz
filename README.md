# ShopWithEzz

ShopWithEzz is a simple Android shopping-list app for planning a shop, tracking a budget, scanning items, and managing a list while you are in the store.

## What it does

- Create and manage shopping lists.
- Set a budget and see the estimated total and amount left.
- Use Budget Bomb when a list goes over budget, with a quick way to change the budget.
- Add items by typing, barcode scanning, photo import, or hands-free voice input.
- Share, print, back up, and restore shopping lists.
- Use a 31-day trial with optional in-app reminders during the final seven days.
