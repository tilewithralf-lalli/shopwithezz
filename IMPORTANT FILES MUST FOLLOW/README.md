# ShopWithEzz files

Use these files in this order:

1. **SHOPWITHEZZ_CURRENT_MASTER.md** — the current app status and plan.
2. **SHOPWITHEZZ_RELEASE_CHECKLIST.html** — the tappable app and release checklist.
3. **SHOPWITHEZZ_GOOGLE_PLAY_HANDOVER.md** — only the Google Play release record.

Supporting file:

- **GOOGLE_PLAY_UPLOAD_KEY_RESET.md** — signing-key history and recovery notes.

The Android source remains in `C:\SWE2`; do not move the `app`, `android`,
`assets`, `constants`, `contexts` or `lib` folders into this documentation
folder because that would break the build project.
