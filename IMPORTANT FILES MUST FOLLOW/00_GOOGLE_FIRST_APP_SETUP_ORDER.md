# GOOGLE-FIRST APP SETUP ORDER — MUST READ FIRST

> **MANDATORY FOR EVERY APP:** Read this single file completely before making any Google Play upload, release, product, billing, testing, or publishing change.

> **NO GOOGLE UPLOADS UNTIL THIS FILE HAS BEEN READ AND THE CHECKLIST HAS BEEN FOLLOWED.**

## Required order

1. Create the Play Console app and confirm package name/application ID.
2. Complete and verify the developer and merchant payments profile, including payout details.
3. Confirm Google Play Billing is enabled and decide the product ID before coding.
4. Create the one-time product, age rating, availability, regional prices, and customer-facing wording.
5. Make the app use the exact product ID and include the Google Play Billing permission.
6. Build an AAB with an incremented version code and upload it to Internal testing.
7. Roll out the test release, install it from Google Play, and test purchase, Restore purchase, entitlement persistence, walkthrough, and relaunch.
8. Only after that complete store listing, testing, review, and production release work.

## Hard stops

- An APK installed locally does not prove Google Play Billing works.
- Do not activate a paid product until a billing-ready AAB is uploaded and rolled out to a test track.
- Do not rebuild for website or text-only changes unless the app binary changed.
- Do not claim Google Play is ready without checking the actual Play Console state.
- Do not use the word “trial” in customer-facing copy.
