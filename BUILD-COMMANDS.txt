SHOPWITHEZZ - SAVED ANDROID COMMANDS
====================================

Use these commands in Windows Command Prompt (CMD).
Do not type PowerShell commands such as $env:... in CMD.


NORMAL DAILY TESTING
--------------------

cd /d C:\SWE2
npx expo start --dev-client

Keep this window open while testing the app.
For ordinary JavaScript and design changes, press R in this window or reload
the app on the phone. You do not normally need to rebuild.


FULL ANDROID REBUILD AND INSTALL
--------------------------------

Use this after adding or changing native Android features.

cd /d C:\SWE2\android
set NODE_ENV=development
gradlew.bat app:installDebug -x lint -x test -PreactNativeArchitectures=arm64-v8a

When it says BUILD SUCCESSFUL and Installed on 1 device, start Metro:

cd /d C:\SWE2
npx expo start --dev-client


IF METRO LOOKS STUCK OR USES OLD FILES
--------------------------------------

cd /d C:\SWE2
npx expo start --dev-client --clear


WHEN A FULL REBUILD IS NEEDED
-----------------------------

- A native package was added or removed.
- Android permissions or intent filters changed.
- app.json native configuration changed.

Normal screen, wording, colour, layout and JavaScript changes only need Metro
reload; they do not need another Gradle rebuild.
